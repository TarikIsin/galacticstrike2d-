# 🚀 GalacticStrike 2D

A 2D space shooter prototype built with Unity. Pilot your spaceship, fend off enemy waves, and survive in the void of space.

---

## 🎮 Gameplay

- Enemy waves spawn and fly toward you — destroy them all before they pass
- If you fail to eliminate the wave, they come back again
- Survive as long as you can and clear every wave

---

## 🕹️ Controls

| Input | Action |
|---|---|
| `W A S D` | Move spaceship |
| `Left Click` | Shoot |

---

## ✨ Features

- 🌊 **Wave-based enemy system** — enemies keep coming back if you miss any
- 🌌 **Scrolling space background** — gives the feeling of flying through space
- 🪐 **Random planet generation** — planets appear in the background as you travel
- 🔫 **Player shooting** — fire at enemies with mouse click

---

## 🛠️ Built With

- **Unity** (2D)
- **C#**

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/TarikIsin/galacticstrike2d-.git
   ```
2. Open the project in **Unity 2022.3+**
3. Open the scene under `Assets/Scenes/`
4. Press **Play**

---

## 📌 Notes

This is a **prototype / demo project** — one level, one wave loop, built to explore Unity 2D mechanics like movement, shooting, enemy AI, and procedural background generation.
